# Invariants and evidence

Status describes enforcement at this source revision, not a claim that every test ran on the reader's machine. Some tests skip by design: PostgreSQL tests need `AQUILA_TEST_POSTGRES_URL`, the pair test (`TestPairUpFromTrees`) needs `AQUILA_TEST_DOCKER=1`, the sandbox tests skip without a `docker` binary, and `TestKilledWorkerTaskRecoversAndStaleCommitIsRejected` is skipped under `go test -short`. Tests are colocated with their package. “Partial” identifies a narrower enforced property or missing proof.

The required A-loses-lease/B-commits/A-returns ordering is covered by `internal/worker/chaos_test.go:TestKilledWorkerTaskRecoversAndStaleCommitIsRejected`: it kills a real worker process, advances expiry in an in-memory store, completes replacement work, and then rejects the stale commit. This proves the sequence over that store/RPC path, not PostgreSQL crash durability. The narrower memory/RPC stale tests reject A after reassignment before B commits.

Additional policy tests in `internal/validate/decide_test.go` enforce all impacted routes, actual latency samples, distinct targets, analyzed changes, and accepted/disclosed caller inference. The current scope is described in [experiments](EXPERIMENTS.md), [execution](EXECUTION_MODEL.md), and [security](SECURITY.md).
